# ClassPulse 기획서

## 1. 프로젝트 개요

### 1.1 프로젝트명

**ClassPulse** (클래스펄스)

### 1.2 한 줄 정의

IT 학원 수강생의 학습 상태를 AI로 모니터링하고, 취업까지 밀착 코칭하는 통합 관리 플랫폼

### 1.3 배경 및 필요성

국비지원 IT 교육 시장은 매년 급성장하고 있으나, 학원 현장에서는 여전히 아래와 같은 문제가 반복되고 있습니다.

**문제 1 — 학생 이탈을 사전에 감지하지 못함**  
출석률 저하, 과제 미제출, 감정 소진이 누적되어 중도 탈락이 발생하지만, 멘토는 이미 심각해진 뒤에야 인지합니다. 학생 1인당 멘토의 관리 가능 인원 초과로 개별 케어가 사실상 불가능합니다.

**문제 2 — 취업 준비 지원의 부재**  
수료 후 취업 준비를 혼자 시작하는 학생 대부분이 자소서 작성, 채용공고 해석, 포트폴리오 방향 설정에서 막힙니다. 학원 입장에서도 수료생 취업 지원을 위한 전담 인력과 시스템이 없습니다.

**문제 3 — 멘토-학생 커뮤니케이션 단절**  
상담을 원해도 예약 방법이 불편하거나 멘토의 가용 시간을 알 수 없어 포기하는 경우가 많습니다. 상담 이력과 피드백도 별도 관리되지 않아 연속성이 없습니다.

## 3. 솔루션 설계

### 3.1 핵심 기능 요약

ClassPulse는 5개의 핵심 기능 모듈로 구성됩니다.

**① 학습 심박수 (Learning Pulse)**  
매일 학생의 출석, 과제 완료 여부, 감정 상태, 질문 횟수를 수집합니다. AI가 7가지 지표를 종합하여 위험도(0~100점)와 위험 레벨(GREEN/YELLOW/ORANGE/RED)을 자동 산출합니다. ORANGE 이상 시 담당 멘토에게 즉시 알림을 발송합니다.

**② 채용공고 AI 딥 애널라이저**  
채용공고 URL을 입력하면 Jina Reader가 해당 공고와 기업 홈페이지, 기술 블로그를 자동 크롤링합니다. GPT-4o-mini가 핵심 정보를 요약하고, GPT-4o가 학생 프로필과 비교하여 매칭 점수, 면접 예상 질문 20개, 자소서 가이드, 포트폴리오 개선 방향을 제공합니다.

**③ AI 문서 코치**  
자기소개서·포트폴리오를 업로드하면 AI가 종합 점수와 섹션별 개선점을 피드백합니다. 채용공고와 연동한 타겟팅 피드백도 지원하며, 멘토가 직접 수정본을 제안하는 워크플로우를 포함합니다.

**④ 멘토 상담 예약**  
멘토가 상담 가능 시간(요일·시간대)을 등록하면, 학생은 빈 슬롯을 선택해 예약합니다. 예약·확정·완료·취소 전 단계에서 알림이 발송됩니다.

**⑤ AI 브릿지 레슨 & 감정 체크인**  
수업에서 어려운 주제가 생기면 AI에게 재설명을 요청할 수 있습니다. 주 1회 감정 체크인(FIRE/HAPPY/NEUTRAL/TIRED/EXHAUSTED)을 하면 AI가 상황에 맞는 응원 메시지를 제공합니다.

### 3.2 차별화 포인트

**AI 하네스(Harness) 패턴 적용**  
모든 AI 호출에 역할·톤·규칙·금지사항을 구조화하여 프롬프트로 조립합니다. 일관된 응답 품질과 안전성을 보장하며, 프롬프트 변경 없이 컨텍스트만 교체하는 재사용 가능한 구조입니다.

**2-Tier 모델 라우터**  
저비용의 GPT-4o-mini(TIER 1)가 전체 AI 호출의 약 90%를 처리하고, GPT-4o(TIER 2)는 심층 분석이 필요한 10%에만 사용합니다. 품질 저하 없이 운영 비용을 대폭 절감합니다.

**2단계 채용공고 분석 파이프라인**  
Jina Reader → GPT-4o-mini 요약 → GPT-4o 심층 분석으로 이어지는 파이프라인은 불필요한 토큰 소비를 최소화하면서도 기업 홈페이지·기술 블로그까지 아우르는 풍부한 분석을 가능하게 합니다.

## 4. 기술 스택

### 4.1 전체 아키텍처

```
[Client]
  Next.js 15 (App Router) + React 19 + TypeScript
  Tailwind CSS + Zustand (상태관리)
        ↕
[API Layer]
  Next.js API Routes (Node.js Runtime)
  Vercel Cron (스케줄 작업)
        ↕
[AI Layer]
  OpenAI GPT-4o / GPT-4o-mini
  Jina Reader API (웹 크롤링)
  AI Harness Engine (프롬프트 조립)
  2-Tier Model Router (비용 최적화)
        ↕
[Data Layer]
  Supabase (PostgreSQL)
  Supabase Auth (JWT 인증)
  Supabase Row Level Security
```

### 4.2 기술 선택 이유

**Next.js 15 (App Router)**  
서버 컴포넌트와 API 라우트를 하나의 프레임워크에서 관리할 수 있어 별도의 백엔드 서버가 불필요합니다. Vercel 배포 시 Edge Function, Cron, Node.js Runtime을 유연하게 선택할 수 있습니다.

**Supabase**  
PostgreSQL 기반의 BaaS로, RLS(Row Level Security)를 통해 사용자 역할별 데이터 접근을 DB 수준에서 통제합니다. Supabase Auth를 사용해 별도의 인증 서버를 구축하지 않아도 됩니다.

**OpenAI GPT-4o / GPT-4o-mini**  
채용공고 분석·문서 피드백 등 고품질이 요구되는 작업에는 GPT-4o를, 감정 응답·요약 등 속도와 비용이 중요한 작업에는 GPT-4o-mini를 선택적으로 사용합니다.

**Jina Reader**  
robots.txt 우회, JS 렌더링 페이지 처리, 마크다운 변환을 모두 지원하여 별도의 크롤러 인프라 없이 채용공고와 기업 홈페이지를 추출할 수 있습니다.

## 6. 개발 단계 계획

### Phase 1 — 코어 MVP (완료)
- Supabase 인증 (로그인·회원가입)
- 학습 심박수 기록 및 위험도 계산

- 멘토 수정본 제안 워크플로우

## 7. 기대 효과

**학원 운영자**  
멘토 1인이 관리 가능한 학생 수를 2배 이상 확대합니다. 중도 탈락률을 낮춰 수료 인원과 취업률을 높이고, 이는 학원의 평판과 재등록률로 이어집니다.

**수강생**  
AI 코치를 24시간 이용할 수 있어 취업 준비의 시작 장벽이 낮아집니다. 자신의 학습 상태를 수치로 확인하며 자기 주도 학습 습관을 형성할 수 있습니다.

**멘토**  
위험 학생 알림을 받아 선제적으로 개입할 수 있습니다. 반복적인 자소서 피드백 업무 부담이 줄어들고, 멘토는 고품질 1:1 상담에 집중할 수 있습니다.
